# 世界樹と還る光 2D 試作

小人（リネ族）が根灯りの村から浅い坑道へ潜り、琥珀鉱を掘って持ち帰り、村に小屋と工房を建ててランタンを作る、までを遊べる最初の試作です。
企画の元になった設定書と企画書は、Claude のプロジェクト（Kobito_2D）の `design/kobito2d_plan_v1.md` にあります。

## 動かし方

1. [Godot 4.4 以降](https://godotengine.org/download/)（標準版、.NET でない方）を入れる
2. Godot を起動し「インポート」でこのフォルダの `project.godot` を開く
3. 右上の ▶（F5）で実行

村の左半分（坑道の入口・工房・市場）は `art/village_base.png` の背景絵をそのまま使っています。主人公は `art/player_source.png` の1枚絵をパーツ（体・ひじから先の腕・脚2本）に分け、つるはしを描き足して、関節を回す切り絵アニメで動かしています。それ以外の絵（生き物・坑道のタイル・建築部品・空き地の奥の森）はコードで描いた仮の図形です。

## 操作

| 操作 | キーボード | ゲームパッド |
|---|---|---|
| 歩く | A / D（← →） | 左スティック・十字 |
| 走る | 歩きながら K / C / Shift を押し続ける | RB 押し続け |
| ジャンプ | Space / Z | A |
| 滑空 | 落ちている間ジャンプ長押し | A 長押し |
| 攻撃・掘る | J / X（W・S を押しながらで上下） | X |
| ダッシュ | K / C / Shift を押した瞬間 | RB / B |
| 話す・坑道に入る・作業台・出口 | E | Y |
| 坑道から村へ帰る | E 長押し | Y 長押し |
| 建築モード | B（1〜7 で部品、左クリックで置く、右クリックで外す） | （未対応） |

## 試作に入っているもの

- **村**：背景絵の坑道の入口と市場、住民 3 人（バルド・ネリ・ルカ）、右側の自由に建築できる空き地
- **建築**：床・壁・入口・屋根・奥の壁・作業台・ランタン灯を格子に置く。外すと材料が全部戻る
- **工房**：作業台を屋根（か上の床）と左右の壁（か入口）で囲うと工房として働く。E でランタンとつるはし強化を作れる
- **坑道**：入るたびに 4×4 部屋をランダムにつないで生成。下の段ほど暗く、ランタンがないとほとんど見えない
- **採掘**：土は 1 回、枯れた根の外皮 2 回、琥珀鉱 3 回、硬い岩 4 回で壊れる（つるはし強化で半分）。生きた太い根と外周の岩盤は掘れない
- **生き物**：アリ（殻を落とす）、クモ（跳びかかる・糸を落とす）、最下段の主・大甲虫（突進して壁で目を回す。目を回している間は 2 倍効く）。鉱石は生き物からは出ない
- **倒れたとき**：仲間に村まで運ばれる。その回の収穫の半分を落とし、次に坑道へ入ると入口近くに袋がある
- **保存**：持ち物・道具・建てた部品は自動で保存（`user://save.json`）

## 主人公のアニメ

| 動き | 中身 |
|---|---|
| 待機 | 呼吸で少し伸び縮み |
| 歩行・走行 | 脚を交互に振り、体を上下に揺らす。走行は前傾して速く |
| ジャンプ・落下・滑空 | 上昇中は脚をたたむ、落下中は腕を広げる、滑空中は葉を頭上に持つ |
| 横振り（戦闘・横の採掘） | 後ろに振りかぶって前へ振り抜く |
| 縦振り（足元・上の採掘） | 頭の上から前の下へ振り下ろす（上を掘るときは下から上へ） |

キャラ絵を描き直したら `python tools/make_player_parts.py 元絵.png art/player` でパーツを作り直せます（Pillow・numpy・opencv-python が必要。切り分ける位置は今の絵に合わせた数値なので、構図が変わったら調整が要ります）。

## BGM

`audio/rootlight_village_8bit.ogg` が村でも坑道でも繰り返し流れます。曲を替えるときは `audio/` に置いて、`scripts/game.gd` の `MAIN_BGM` のファイル名を書き換えます。

## フォルダ構成

```
scenes/       village.tscn（最初の場面）, mine.tscn
scripts/
  game.gd           持ち物・道具・保存・場面切り替え（自動読み込み Game）
  player.gd         小人の操作とカメラ
  player_visual.gd  主人公の切り絵アニメ
  tiles.gd          地形タイルの種類・硬さ・落とす材料（絵の差し替えはここ）
  mine.gd           坑道の生成・掘る・暗さ・帰還
  mine_rooms.gd     坑道の部屋テンプレート（手作り、文字で書く）
  village.gd        村
  build_system.gd   自由建築と工房の判定
  built_part.gd     建築部品の見た目
  creature.gd       生き物の共通部分（ant.gd, spider.gd, beetle.gd）
  pickup.gd         落ちている材料
  hud.gd            画面表示と工房のメニュー
  npc.gd            村の住民
tests/
  smoke.gd          通しの自動確認
  shots.gd          画面写真の自動撮影
```

## 自動確認

```
godot --headless --path . -- --smoke
```

村で工房を建てる → ランタンを作る → 坑道を生成して掘る・倒す → 倒れて村へ戻る → 落とし物の袋がある、までを確かめ、最後に `SMOKE OK` と出ます。
