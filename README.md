# 世界樹と還る光 2D 試作

小人（リネ族）が根灯りの村から浅い坑道へ潜り、琥珀鉱を掘って持ち帰り、村に小屋と工房を建ててランタンを作る、までを遊べる最初の試作です。
企画の元になった設定書と企画書は、Claude のプロジェクト（Kobito_2D）の `design/kobito2d_plan_v1.md` にあります。

## 動かし方

1. [Godot 4.4 以降](https://godotengine.org/download/)（標準版、.NET でない方）を入れる
2. Godot を起動し「インポート」でこのフォルダの `project.godot` を開く
3. 右上の ▶（F5）で実行

村の左半分（坑道の入口・工房・市場）は `art/village_base.png` の背景絵をそのまま使っています。主人公は `art/player_source.png` の1枚絵をパーツ（体・ひじから先の腕・脚2本）に分け、つるはしを描き足して、関節を回す切り絵アニメで動かしています。坑道の絵は `art/mine/` の手描き素材です（元の素材は `art_src/`、地面タイルは `tools/build_mine_tiles.py` で組み立て）。森の絵は `art/forest/` の手描き素材です（元の素材は `art_src/berry_forest_all_images_36/`・`art_src/berry_transport_11_4/`・`art_src/berry_mid_trees/`（中景の木）・`art_src/berry_climb_tree/`（登れる大木）、`tools/build_forest_art.py` で大きさをそろえて書き出し）。それ以外の絵（生き物・建築部品・空き地の奥の森）はコードで描いた仮の図形です。

## 操作

| 操作 | キーボード | ゲームパッド |
|---|---|---|
| 歩く | A / D（← →） | 左スティック・十字 |
| 走る | 歩きながら K / C / Shift を押し続ける | RB 押し続け |
| ジャンプ | Space / Z | A |
| 滑空 | 落ちている間ジャンプ長押し | A 長押し |
| 攻撃・掘る | J / X（W・S を押しながらで上下） | X |
| ダッシュ | K / C / Shift を押した瞬間 | RB / B |
| 話す・坑道や森に入る・作業台・出口 | E | Y |
| 坑道から村へ帰る | E 長押し | Y 長押し |
| 建築モード | B（1〜7 で部品、左クリックで置く、右クリックで外す） | （未対応） |

## 試作に入っているもの

- **村**：背景絵の坑道の入口と市場、住民 3 人（バルド・ネリ・ルカ）、右側の自由に建築できる空き地
- **建築**：床・壁・入口・屋根・奥の壁・作業台・ランタン灯を格子に置く。外すと材料が全部戻る
- **工房**：作業台を屋根（か上の床）と左右の壁（か入口）で囲うと工房として働く。E でランタンとつるはし強化を作れる
- **坑道**：入るたびに 4×4 部屋をランダムにつないで生成。下の段ほど暗く、ランタンがないとほとんど見えない
- **坑道の見た目**：遠景・中景・足場タイル・鉱脈・飾り・前景の層に分けて重ねる。絵は `art/mine/`（作り方は `art/mine/README.md`）。床の縁の苔・小石・結晶・ランタン・垂れた根は自動で置く
- **はしご・吊り橋**：はしごは W/S でつかまって登り降り、ジャンプで離れる。部屋どうしの縦穴にもはしごがかかる
- **採掘**：土は 1 回、枯れた根の外皮 2 回、琥珀鉱 3 回、硬い岩 4 回で壊れる（つるはし強化で半分）。生きた太い根と外周の岩盤は掘れない
- **生き物**：アリ（殻を落とす）、クモ（跳びかかる・糸を落とす）、最下段の主・大甲虫（突進して壁で目を回す。目を回している間は 2 倍効く）。鉱石は生き物からは出ない
- **倒れたとき**：仲間に村まで運ばれる。その回の収穫の半分を落とし、次に坑道へ入ると入口近くに袋がある
- **ベリーの森**：村の右端の立て札（森へ）で E。茨の枝が足場になっていて、枝に木苺が実っている
  - 実を攻撃すると落ちる（青い実は落ちない）。乗っている枝の上で下攻撃（S+J）すると枝が揺れて、熟した実がまとめて落ちる
  - 落ちた実は転がる。歩いてぶつかると押せて、ダッシュ（K）で体当たりすると弾け飛ぶ。大きな野苺は重い
  - 籠に入って止まった実が収穫になる。籠の上の枝から直接落とすか、横の葉の坂を押し上げて入れる
  - 入口の立て札（村へ）で E を押すと村へ戻る
- **保存**：持ち物・道具・建てた部品は自動で保存（`user://save.json`）

## 主人公のアニメ

| 動き | 中身 |
|---|---|
| 待機 | 呼吸で少し伸び縮み |
| 歩行・走行 | 脚を交互に振り、体を上下に揺らす。走行は前傾して速く |
| ジャンプ・落下・滑空 | 上昇中は脚をたたむ、落下中は腕を広げる、滑空中は葉を頭上に持つ |
| 横振り（戦闘・横の採掘） | 後ろに振りかぶって前へ振り抜く |
| 縦振り（足元・上の採掘） | 頭の上から前の下へ振り下ろす（上を掘るときは下から上へ） |

キャラ絵を描き直したら `python tools/make_player_parts.py 元絵.png art/player` でパーツを作り直せます（Pillow・numpy・opencv-python が必要。切り分ける位置は今の絵に合わせた数値なので、構図が変わったら調整が要ります）。

## BGM

`audio/rootlight_village_recorded.ogg` が村でも坑道でも繰り返し流れます。曲を替えるときは `audio/` に置いて、`scripts/game.gd` の `MAIN_BGM` のファイル名を書き換えます。

森では `audio/village_under_world_tree.ogg`（`FOREST_BGM`）が流れます。Godot は MIDI をそのまま鳴らせないので、`village_under_world_tree.mid` を General MIDI の音色（FluidR3_GM）で録音して .ogg にしています。MIDI を直したら、次のように作り直せます（fluidsynth と ffmpeg が必要）。

```
fluidsynth -ni -g 0.6 -r 44100 -F forest.wav FluidR3_GM.sf2 audio/village_under_world_tree.mid
ffmpeg -i forest.wav -t 178.86 -af volume=7dB -c:a libvorbis -q:a 5 audio/village_under_world_tree.ogg
```

`-t` は曲の長さ（秒）。末尾の余韻を切って、繰り返したときに間が空かないようにしています。

## フォルダ構成

```
scenes/       village.tscn（最初の場面）, mine.tscn, forest.tscn
scripts/
  game.gd           持ち物・道具・保存・場面切り替え（自動読み込み Game）
  player.gd         小人の操作とカメラ
  player_visual.gd  主人公の切り絵アニメ
  tiles.gd          地形タイルの種類・硬さ・落とす材料（絵の差し替えはここ）
  mine.gd           坑道の生成・掘る・暗さ・帰還
  mine_rooms.gd     坑道の部屋テンプレート（手作り、文字で書く）
  forest.gd         ベリーの森（枝の足場・実・籠・葉の坂の配置と収穫）
  forest_art.gd     森の絵の読み込みと、絵に合わせた当たり判定の位置
  berry.gd          森の実（ぶら下がる・落ちる・転がる・押される）
  village.gd        村
  build_system.gd   自由建築と工房の判定
  built_part.gd     建築部品の見た目
  creature.gd       生き物の共通部分（ant.gd, spider.gd, beetle.gd）
  pickup.gd         落ちている材料
  hud.gd            画面表示と工房のメニュー
  npc.gd            村の住民
tests/
  smoke.gd          通しの自動確認
  shots.gd          画面写真の自動撮影
```

## 自動確認

```
godot --headless --path . -- --smoke
```

村で工房を建てる → ランタンを作る → 坑道を生成して掘る・倒す → 倒れて村へ戻る → 落とし物の袋がある → 森で実を落とす・枝を揺らす・押す・体当たり・坂から籠に入れる → 村へ戻る、までを確かめ、最後に `SMOKE OK` と出ます。
