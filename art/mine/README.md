# 坑道の絵

ゲームが読み込む坑道の絵です。元の素材は手元の `art_src/mine_assets_v1/png/`（「坑道グラフィック制作要件」に沿って描いたもの）で、
地面タイルだけはそこから組み立てています。素材を描き直したら、次のコマンドで作り直します。

    python3 tools/build_mine_tiles.py art_src/mine_assets_v1/png art/mine

- 地面の 1マスは 64×64px。ゲームの中では半分の 32px に縮めて使います。
- 素材の名前・大きさ・描き方の決まりは「坑道グラフィック制作要件」を参照してください。

## 組み立てるもの

| ファイル | 中身 |
|---|---|
| `terrain.png` | 512×1024。行 = そのマスの上・右・下・左に地面が続いているか（上1 + 右2 + 下4 + 左8）。列 = 柄 8 通り。`edge_top` / `edge_bottom` / `edge_side` を重ね、空気に面する角を丸く削って作る |
| `terrain_fill.png` | まわりが全部地面のマス。`rock_texture` を半分に縮めて 2×2 に並べ、縁の岩の色に合わせたもの。8×8 マスに切って位置で選ぶ |

柄は、横に続く縁なら x 座標、縦に続く縁なら y 座標で選ぶので、縁の帯が途切れずにつながります。
`corners.png` は岩の描き方がほかの縁と合わなかったので使っていません。

## そのまま使うもの

遠景 `far`、すり抜け足場 `platform_root` / `platform_plank`、はしご `ladder`、吊り橋の柱 `bridge_post`、
鉱脈 `ore_*`、飾り `deco_*`（`_v2` は別案で、ランダムに半々で使う）、中景 `mid_*`、前景 `fg_*`。
